# Ankit Maurya — Data Science & AI Portfolio

A single-path portfolio for data exploration, machine-learning systems, and
production-minded experiments. The visual language is a Kyoto night path: warm
lantern light, dark glass panels, and quiet motion.

## Stack

- Next.js 16 and React 19
- TypeScript
- Framer Motion
- Supabase for optional stats and contact submissions
- CSS Modules and `next/font`

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Checks

```bash
npm run lint
npm run build
```

Supabase is optional during local development. Without the public Supabase
environment variables, the site uses its static hero stats and the contact form
shows the direct LinkedIn and GitHub routes.
